# Swift Tax Rules

Opensource tax rules for multiple countries in CEL (Common Expression Language)

This is built for [Swift Payroll Engine](https://github.com/borjes-tech/swift_payroll_engine)

## Countries

Packs written so far (all **unverified**; see [TO_CONFIRM.md](TO_CONFIRM.md) before using any of them):
Bangladesh (bd), Egypt (eg), Ghana (gh), Hong Kong (hk), Indonesia (id), India (in), Kenya (ke), Morocco (ma),
Malaysia (my), Nigeria (ng), Pakistan (pk), Turkey (tr), Uganda (ug).

Gambia (gm) has a placeholder with no figures yet.

Run `swift_payroll_engine check-rules countries` from the engine to load every pack and run its tests.
